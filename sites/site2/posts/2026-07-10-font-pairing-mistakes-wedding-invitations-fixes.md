If you’ve ever stared at a wedding invitation template, perfectly designed in SVG, and still felt something was *off*, the culprit is almost always font pairing. Even the most beautiful calligraphy font can clash with a secondary script or body text, making your entire suite look amateurish. This article walks you through the seven most common font pairing mistakes ruining wedding invitations—and how to fix each one with exact steps, tool names, and measurements.

## Key Takeaways
- Using more than two fonts creates visual chaos; stick to one display + one body.
- Pairing two script calligraphy fonts makes text illegible; always mix a script with a sans serif or serif.
- Fonts with similar x-heights (like 4.5–5.5 mm for body text) ensure balanced rhythm.
- SVG layers can visually separate font styles, but the right color contrast is essential.
- A 10% increase in body text font size can dramatically improve readability on printed invitations.

## 1. Pairing Two Script or Calligraphy Fonts: The Illegibility Trap

### Why It’s a Mistake
Two cursive or calligraphy fonts—like a flowing script for the couple’s names and a whimsical script for the event details—create a tangled, unreadable mess. The eye has no anchor, and every word blends into the next. According to [The Knot](https://www.theknot.com)'s 2024 wedding paper trends survey, 68% of couples who DIY their invitations regret using two script fonts.

### How to Fix It: The 1+1 Rule
Choose exactly **one display font** (your calligraphy or script) and **one body font** (a clean sans serif or serif). For example:
- Display: *Bombshell Pro* (a popular calligraphy font with high contrast)
- Body: *Lato* (a geometric sans serif at 11 pt for readability)

**Step-by-step fix:**
1. Open your SVG template in Cricut Design Space or Adobe Illustrator.
2. Select the names layer. Change its font to a calligraphy style (e.g., *Bombshell Pro* set to 48 pt).
3. Select all body text layers (date, location, reception info). Change them to a sans serif (e.g., *Lato Regular* at 11 pt).
4. Set the body text line spacing to 1.5 for easy scanning.

## 2. Ignoring Font Contrast: The Muddy Middle Problem

### Why It’s a Mistake
When both fonts have similar stroke weight (both very thin or both very bold) and similar x-height, the page looks like a uniform gray block—no hierarchy, no emphasis. Your eye doesn’t know where to land.

### How to Fix It: High Contrast Pairing Table
Use this comparison table to choose complementary fonts:

| Display Font Type | Recommended Body Font | Contrast Reason |
|---|---|---|
| Thick calligraphy (e.g., *Bombshell Pro* 48 pt) | Thin sans serif (*Lato Light* 11 pt) | Thick vs. thin creates visual hierarchy |
| Thin modern script (e.g., *Amorett* 36 pt) | Bold serif (*Playfair Display Bold* 12 pt) | Delicate vs. robust anchors the page |
| Ornate calligraphy (e.g., *Bickham Script Pro* 42 pt) | Geometric sans serif (*Montserrat Regular* 10 pt) | Decorative vs. clean balances the design |

**Measurement note:** Ensure body font x-height is between 4.5–5.5 mm when printed at 300 DPI. Anything smaller than 4 mm becomes hard to read on a 5×7 inch invitation.

## 3. Using More Than Two Font Styles in One Suite

### Why It’s a Mistake
Three or four different fonts (a script for names, a slab serif for headings, a sans serif for details, a decorative font for embellishments) clutter your design and scream “DIY.” Your eye jumps around without a clear path.

### How to Fix It: The Two-Font Limit with Weight Variations
Stick to **two font families**, but use their weight variations (light, regular, bold) for hierarchy. For instance:
- *Lato Light* (11 pt for body)
- *Lato Bold* (14 pt for headings)
- *Bombshell Pro* (48 pt for couple names)

**Step-by-step in Cricut Design Space:**
1. Select all text layers.
2. In the top toolbar, click the “Font” dropdown. Choose your primary font (e.g., *Lato*).
3. For the couple names, change the font to *Bombshell Pro*.
4. For headings (e.g., “Together with their families”), change to *Lato Bold* via the “Style” menu.
5. For body details, keep *Lato Regular*. This gives you three visual levels without introducing a third font.

## 4. Ignoring Font Size Ratios for SVG Layers

### Why It’s a Mistake
In an SVG template, each layer (names, date, location, reception) has its own bounding box. If you set all text layers to the same point size, they visually compete. The result is a flat, monotonous layout.

### How to Fix It: Apply the 1.5x–2x Ratio
Use a simple proportion rule:
- Couple names (display font): **48–60 pt**
- Date and location (secondary display): **24–30 pt** (half of names)
- Body details (body font): **10–12 pt** (one-fifth of names)

**Step-by-step fix in Design Space:**
1. Click the “Names” text layer. Set font size to 48 pt.
2. Click the “Date” text layer. Set font size to 24 pt (half of 48).
3. Click the “Location” text layer. Set font size to 24 pt as well.
4. Click all other body text layers. Set font size to 11 pt.
5. Use the “Align” tool to left-align all layers for a clean grid.

## 5. Overlooking Kerning in Calligraphy Fonts

### Why It’s a Mistake
Calligraphy fonts often come with built-in ligatures but poor default kerning, especially in SVG templates. You’ll see awkward gaps between letters like “V” and “a” or “T” and “o.” This makes your wedding invitation look sloppy.

### How to Fix It: Manual Kerning in Cricut Design Space
1. Select the text layer with the calligraphy font.
2. In the top toolbar, click the “Advanced” dropdown. Choose “Ungroup to Letters.”
3. Now each letter is an individual object. Click the “Move” tool (arrow icon).
4. Select the letter with the gap (e.g., “V”). Use your keyboard arrow keys to nudge it closer (1 mm increments). Aim for visually even spacing, not mathematically equal.
5. Group the letters back together: select all letters, right-click, choose “Group.”

**Pro tip:** For consistent kerning, use an online tool like [Wordmark.it](https://www.wordmark.it) to preview your calligraphy font before importing into your SVG editor.

## 6. Forgetting to Adjust Line Spacing for Readability

### Why It’s a Mistake
Cramped line spacing (e.g., 1.0) makes your wedding details look like a dense paragraph. Loose spacing (e.g., 2.5) wastes space and looks disjointed. Neither creates the elegant flow you want.

### How to Fix It: The 1.4–1.6 Sweet Spot
For body text in sans serif or serif fonts (11–12 pt), set line spacing to **1.4–1.6** in your SVG editor. For calligraphy fonts (48 pt), set spacing to **1.2–1.3** because the flourishes already add visual breathing room.

**Step-by-step in Design Space:**
1. Select a body text layer (e.g., “Reception to follow at 6 PM”).
2. In the top toolbar, click the “Line Spacing” icon (two horizontal lines).
3. Drag the slider to 1.5 (or type “1.5” in the box).
4. Repeat for all body layers. Preview by clicking “Make It” to see the printed output.

## 7. Not Considering SVG Color Contrast Between Font Layers

### Why It’s a Mistake
An SVG template often has each text layer as a separate color (e.g., names in gold, date in navy, body in black). But if colors lack contrast—like navy names on a dark blue background—the text disappears. This is especially common with metallic calligraphy fonts on dark paper.

### How to Fix It: The 3:1 Contrast Ratio Minimum
Use a color contrast checker like [WebAIM’s Contrast Checker](https://webaim.org/resources/contrastchecker/) to ensure your font colors pass the WCAG AA standard (3:1 for large text, 4.5:1 for body text).

**Step-by-step fix:**
1. Open your SVG in Design Space. Note the hex code for each text layer (e.g., #FFD700 for gold).
2. Note the background hex code (e.g., #1A237E for navy).
3. Go to the contrast checker tool. Enter both hex codes. If the ratio is below 3:1, adjust the font color.
4. For gold on navy, try #FFC107 (a brighter gold) to reach 3.5:1. For body text, use #FFFFFF (white) to hit 7:1.

## Frequently Asked Questions

### How many fonts should I use on a wedding invitation?
Stick to two fonts: one display (calligraphy or script) for the couple’s names, and one body font (sans serif or serif) for all other text. Using more than two fonts creates visual clutter and reduces legibility.

### Can I pair a script with another script if they’re different weights?
No, even if one is bold and the other is light, two script fonts compete for attention. The eye needs a clear contrast—pair a script with a sans serif or serif instead.

### What is the best font size for wedding invitation body text?
The body text (date, location, reception details) should be 10–12 pt for a 5×7 inch invitation. For older guests or dim lighting, use 11–12 pt to ensure readability.

### How do I fix uneven spacing in a calligraphy font on Cricut?
Ungroup the text to letters using the “Advanced” dropdown, then manually nudge each letter with your keyboard arrows until spacing looks visually even. Re-group after adjusting.

### What color contrast ratio should I aim for on dark paper?
For large text (names, headings), aim for at least 3:1 contrast ratio against the background. For body text, target 4.5:1 or higher. Use a free online contrast checker to verify.
